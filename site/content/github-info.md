## Recent GitHub updates

- **New pull request overview page (public preview):** Check what's blocking a long pull request without scrolling past dozens of comments and timeline events. [Source: GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **`pull_request_target` blocked by default from December 2, 2026:** GitHub Actions will block these events in public repositories unless an Actions event policy explicitly allows them. Review your workflows now. [Source: GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **GitHub Copilot in Xcode's coding assistant (public preview):** Use Copilot directly in Xcode's built-in coding assistant. [Source: GitHub Changelog](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant)
