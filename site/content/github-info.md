## Recent GitHub updates

Source: GitHub Blog and GitHub Changelog.

- **GitHub Actions: `pull_request_target` blocked by default on December 2.** Starting December 2, 2026, Actions blocks `pull_request_target` events in all public repositories unless an Actions event policy explicitly allows them. Check your workflows before then. [Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **GitHub Copilot is now available in JetBrains Air.** Delegate coding tasks, guide execution, and review results using the Agent Client Protocol (ACP). [Changelog](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)
- **Dependabot version updates support Agent Package Manager.** Keep AI agent skills, prompts, and instructions up to date through Dependabot pull requests. [Changelog](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager)
- **GitHub Copilot app for beginners: teach Copilot about your codebase.** Add custom instructions and skills to your repository, use custom agents, and connect MCP servers like Playwright. [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/)
