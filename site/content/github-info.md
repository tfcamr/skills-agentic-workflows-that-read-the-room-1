## Recent updates (November 2026)

- **Wait for pull request events with GitHub CLI**: with `gh` v2.105.0, you and your agents can wait for a pull request to change with one command instead of polling. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli/)
- **Customize GitHub Copilot for your team**: team customizations are now generally available, so organization teams can share the Copilot plugins they rely on without every member repeating setup. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team/)
- **Secret scanning on demand**: Copilot's security review specialist now runs secret scanning, catching secrets in code changes before they're merged. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-17-secret-scanning-on-demand-for-developers-and-agents/)
- **Build once, run on any agent**: a practical guide to agent skills, reviewable files that capture repeatable engineering work. Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/)
