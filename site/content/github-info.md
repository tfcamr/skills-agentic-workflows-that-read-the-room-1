## Recent GitHub updates worth watching

- **New pull request overview page (public preview)** – Check what's blocking a long pull request without scrolling past dozens of comments and timeline events. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview/).
- **`pull_request_target` blocked by default on December 2, 2026** – GitHub Actions will block `pull_request_target` events in public repositories unless an Actions event policy explicitly allows them. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2/).
- **Secret scanning now covers GitHub Actions workflow logs** – Alongside issues, wikis, discussions, and pull requests. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs/).
- **Teach Copilot about your codebase** – A beginner-friendly guide to custom instructions, skills, custom agents, and MCP servers like Playwright. Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/).
