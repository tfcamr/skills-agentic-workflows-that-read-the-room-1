## Recent updates

- **Stacked pull requests are generally available.** Break large changes into smaller, focused pull requests that can be reviewed independently and merged together. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available).
- **Dynamic workflows in Copilot CLI and the Copilot app.** Define multi-agent orchestration in code, with steps that run in sequence or in parallel. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app).
- **Async merge API is generally available.** Merge single or stacked pull requests, or add them to a merge queue, from automations without waiting on a single request. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available).
