## Recent updates worth watching

### GitHub collaboration

- **New pull request overview page (public preview):** a cleaner view of what's blocking a long pull request, without scrolling past comments and timeline events. [Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **Issue types and fields for personal accounts:** now generally available on personal-account repositories, so individuals and open source maintainers can standardize planning. [Changelog](https://github.blog/changelog/2026-11-11-issue-types-and-fields-are-available-for-personal-accounts)

### GitHub Copilot

- **GitHub Copilot in Slack and Teams is generally available:** investigate bugs, create issues, implement changes and open pull requests from a conversation. [Changelog](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available)
- **Agent skills guide:** how skills capture repeatable engineering work in reviewable files that teams can reuse. [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/)

### GitHub Actions

- **`pull_request_target` blocked by default from December 2, 2026:** public repositories will block these events unless an Actions event policy allows them, so check your workflows. [Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
