## Recent updates

- **GitHub Agentic Workflows is generally available.** The open source project from GitHub Next lets you automate reasoning-based repository tasks such as issue triage, CI failure analysis, and documentation updates. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available)
- **Shared Copilot Automations are rolling out.** Teams can combine prompts, triggers, and tools to build and maintain AI-powered workflows together. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-28-build-shared-workflows-for-your-team-with-copilot-automations)
