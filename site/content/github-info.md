## Recent GitHub Blog and Changelog stories

- **Stacked pull requests are generally available.** Break a large change into smaller, focused pull requests that are reviewed independently and merged together. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available)
- **`pull_request_target` blocked by default from December 2, 2026.** GitHub Actions will block `pull_request_target` events in public repositories unless an Actions event policy allows them; private and internal repositories are unaffected. Check which workflows depend on it. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Dependabot version updates support Agent Package Manager (APM).** Add an `apm` entry to `.github/dependabot.yml` to keep agent skills, prompts, and instructions declared in `apm.yml` up to date. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager)
